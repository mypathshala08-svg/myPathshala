map asks  300 MB -> app holds 1024 MB = AM 512 + map 512 MB
map asks  384 MB -> app holds 1024 MB = AM 512 + map 512 MB
map asks  600 MB -> app holds 1280 MB = AM 512 + map 768 MB
map asks 1100 MB -> app holds 1792 MB = AM 512 + map 1280 MB
