The problem

Riya needs the extension of a file name, the folder part of a path, the domain of an email, a name in capitals and a neatly aligned table. Her first scripts call basename, sed, awk and tr for each of these, starting a new program every time. Bash can do all of it inside the shell with parameter expansion: ${f%.*} removes an extension, ${email#*@} keeps the domain, ${name^^} makes capitals, ${s/old/new} replaces, ${s:0:3} cuts. printf then prints it all in exact columns. In a loop over 10,000 files this is the difference between seconds and minutes.

By the end of this page you will be able to:
  • measure, cut and slice strings with ${#s} and ${s:start:len}
  • remove prefixes and suffixes with # ## % %% (for extensions, paths, emails)
  • replace, change case and set defaults with ${s/a/b} ${s//a/b} ${s^^} ${s,,} ${s:-x}
  • format output with printf: %s %d %f %x, widths, alignment, padding, -v and %q

2 Definition

String manipulation with parameter expansion, and printf

Formal definition (write this in exams)

Parameter expansion is the bash feature ${…} that returns a changed version of a variable’s value: its length, a substring, the value with a prefix or suffix pattern removed, with text replaced, in another case, or a default. printf is a built-in that prints its arguments according to a format string with conversion specifiers such as %s, %d and %f.

In simple words

Change text with ${…}; print it exactly with printf.

Parameter expansion at four depths

Very basic No jargon: scissors on a ribbon

Cut from the left or the right, a little or a lot.

Basic What you will type

  • echo ${#name}: how many characters.
  • echo ${file%.txt}: drop .txt.
  • echo ${name^^}: capitals.
  • printf '%s is %d\n' Riya 24: formatted line.

Intermediate Patterns and printf

  • Patterns in # % / are globs: * ? [a-z], not regex.
  • ${s/#pre/X} replaces only at the start, ${s/%suf/X} only at the end.
  • ${s:-def} default if empty, ${s:=def} also assigns, ${s:?msg} error, ${s:+alt} alt if set.
  • printf reuses the format until all arguments are used (the three lines in the puzzle).
  • printf -v var … stores the result instead of printing.

Advanced Behind the screen: built-ins, bytes and locales

  • All of these are done by bash itself, no fork/exec; a loop with $(basename "$f") starts a process each time (Lesson 11.1).
  • ${#s} counts characters in the current locale: “café” is 4 in a UTF-8 locale, 5 bytes with LC_ALL=C.
  • Case operators ^^ ,, and ${s: -3} negative offsets need bash 4+ (macOS bash 3.2: “bad substitution”).
  • printf follows C’s printf: %d needs an integer (3.5 is an error), %f floats, %x %o bases, %5.2f width.precision; %b expands backslashes in the argument; %q quotes for re-use as shell input.
  • printf is safer than echo: echo’s handling of -n, -e and backslashes differs between shells.

Did you know? The # / % memory trick is from the bash manual’s own authors: on a US keyboard # sits left of $ (cuts the left) and % sits right of it (cuts the right).

EXAM> “How do you get the length of a string in bash?” → ${#var}. (wc -c also counts the newline and starts a process.)

${#s} · ${s:off} · ${s:off:len} · ${s: -n} length and substrings

🟢 Read-onlyno sudo

${#s} is the number of characters. ${s:off:len} takes len characters from position off (from 0). A negative offset counts from the end but needs a space or brackets: ${s: -3}, otherwise :- is the default operator.

✓ Use it when

  • checking input length
✗ Don’t use it when
  • counting bytes for binary data (use wc -c)

${s#p} · ${s##p} · ${s%p} · ${s%%p} removing prefixes and suffixes

✓ Use it when

✗ Don’t use it when
  • complex patterns (use [[ =~ ]] or sed)

${s/a/b} · ${s//a/b} · ${s/#a/b} · ${s/%a/b} · ${s^^} ${s,,} ${s^} replacing text and changing case

🟢 Read-onlyno sudo

One slash replaces the first match, two slashes every match; /# and /% anchor to the start or end. An empty replacement deletes. ^^ makes everything upper case, ,, lower, ^ only the first letter. A pattern like [aeiou] limits which letters change.

✓ Use it when
  • clean-up of names, spaces, separators
  • case-insensitive comparisons
✗ Don’t use it when
  • regex replacements (sed -E)

printf FORMAT args… · %s %d %f %x · %-10s %05d %.2f · -v · %q printf

🟢 Read-onlyno sudo

printf prints its arguments using the format. Each % conversion takes the next argument; the format repeats until all are used. A number between % and the letter is the width (- left-aligns, 0 pads), a dot gives precision. -v var stores the result. printf never adds a newline on its own.

✓ Use it when
  • every report, table, log line, CSV and fixed-width file
  • numbers with padding or decimals
✗ Don’t use it when
  • echo -e (not portable)

Syntax: printf '%-10s %6.2f\n' name 3.5 · printf -v id 'EMP%04d' 7

Undo and safety net

Parameter expansion never changes the variable unless you assign it (or use :=).

  • Unexpected result: print each step with declare -p or echo "[$s]".
  • Renamed files wrongly: always echo mv first; keep a list (Lesson 3.5).
  • Case operators fail on macOS: use tr or install bash 5.
  • printf output mixed up: count % conversions against arguments.

Error messages decoded

Errors students see most. Each was really produced on our build machine, with its exit status.

  1. printf '%d\n' abc
    /home/riya/script.sh: line 1: printf: abc: invalid number 0 exit status: 1

    What it means: %d needs a number.

    Fix: Use %s, or check input.

  2. s=abc; echo ${s:0:-5}
    /home/riya/script.sh: line 1: -5: substring expression < 0 exit status: 1

    What it means: A negative length that goes past the start.

    Fix: Check ${#s} first.

  3. echo ${ s}
    /home/riya/script.sh: line 1: ${ s}: bad substitution exit status: 1

    What it means: Space after { is not allowed.

    Fix: ${s}.

  4. unset s; echo ${s:?is required}
    /home/riya/script.sh: line 1: s: is required

    What it means: :? stops on empty or unset.

    Fix: Set the variable, or use :-.

Cutting and trimming

V1

Trim spaces from both ends

s='   padded text   '; shopt -s extglob; s=${s##+([[:space:]])}; s=${s%%+([[:space:]])}; echo "[$s]"

V2

Trim with read (no extglob)

read -r s <<< '   padded text   '; echo "[$s]"
[padded text]

Puzzle answer Remember the question from the story? Open to check your guess.

1. %% removes the longest suffix matching .*, which starts at the first dot; one % removes the shortest, from the last dot: report.final.v2. 2. %d accepts only integers; use %.0f or %s. 3. printf reuses its format until every argument is used, so one %s\n and three arguments give three lines (a feature, used for lists). 4. macOS ships bash 3.2, and ^^ needs bash 4: install a newer bash or use tr a-z A-Z.
