awk: fields, patterns and reports

awk turns the command line into a small spreadsheet: it splits lines into columns, selects rows by conditions, adds up and groups numbers, and prints formatted reports. This lesson explains awk step by step and shows how every IT role uses it.

The problem

The CFO wants, by tonight: the average salary per department, only for staff in Pune or Mumbai, as a neat report with a header and a total. cut can take columns, sort can order them, but none of them can compare a value or add numbers per group. awk can: awk -F, '$4=="Pune" || $4=="Mumbai" {s[$3]+=$5; n[$3]++} END {for (d in s) print d, s[d]/n[d]}' employees.csv. awk is a small programming language built for columns.

By the end of this page you will be able to:

  • select lines with patterns and conditions: /ERROR/, $5 > 70000, NR > 1, && ||, ranges
  • calculate totals, averages, counts and per-group sums with variables, arrays and BEGIN/END
  • format reports with printf, and use string functions (length, substr, toupper, gsub, split)

2 Definition

awk: fields, patterns and reports

Formal definition (write this in exams)

awk is a pattern-scanning and text-processing language. It reads input line by line (records), splits each line into fields ($1, $2, …) using a field separator, and for every rule pattern { action } whose pattern is true, runs the action. It has variables, associative arrays, arithmetic, string functions, printf, and special BEGIN and END blocks.

In simple words

For every line: if this, then do that, and at the end print the summary.

awk at four depths

Pick your depth. Completely new? Start at Very basic and climb one step at a time.

Very basic No jargon: a register and a calculator

Think of a teacher with a class register.

  • The register has columns: roll, name, class, marks. awk calls them $1 $2 $3 $4.
  • The teacher reads every row, ticks the ones that match (“marks above 80”), and adds up marks per class.
  • At the end (END) she writes the summary.

Basic The forms you will type every day

  • awk '{print $1}' file: first column (separated by spaces or tabs).
  • awk -F: '{print $1}' /etc/passwd: user names (separator :).
  • awk '/ERROR/' app.log: lines containing ERROR.
  • awk -F, '$5 > 70000' employees.csv: rows where column 5 is above 70000.
  • awk '{s += $2} END {print s}' f: the total of column 2.

Intermediate Patterns, actions, variables

  • A program is pattern { action } pairs. No pattern = every line; no action = print the line.
  • Built-ins: NR line number, NF number of fields, $NF last field, $0 whole line, FS/OFS input/output separator, FILENAME, FNR line number in the current file.
  • Conditions: == != < > <= >=, ~ /re/ (matches), !~, && || !; ranges /start/,/end/.
  • Variables need no declaration and start as 0 or "". Arrays are associative: count[$3]++ uses the department name as the index.
  • BEGIN { } runs before the first line (headers, FS), END { } after the last (totals).

Advanced Behind the screen: one awk, several implementations

  • awk = Aho, Weinberger, Kernighan (Bell Labs, 1977). Today there are several: mawk (Ubuntu’s default awk, very fast), gawk (GNU, more functions: strftime on all versions, asort, -i inplace, networking), and BWK “one true awk” on macOS.
  • for (k in arr) visits keys in an unspecified order; pipe to sort or use gawk’s PROCINFO["sorted_in"].
  • Numbers are floating point (double): sums of money are fine for reports, but round with printf (%.2f).
  • Assigning to a field ($3 = "X") rebuilds $0 with OFS; assigning $1 = $1 is the trick to change separators.
  • NR==FNR is true only while reading the first file: the classic way to join two files in awk.

Did you know? The “K” in awk is Brian Kernighan, co-author of “The C Programming Language”. awk’s syntax looks like C on purpose, and its creators wrote “The AWK Programming Language” (1988; a second edition appeared in 2023, when awk gained CSV support with --csv).

Exam tip: “Print the user names and UIDs of all users with UID ≥ 1000.” → awk -F: '$3 >= 1000 && $3 < 65534 {print $1, $3}' /etc/passwd (explain -F, the condition, and why 65534 (nobody) is excluded).

Quick check What does awk '{print $NF}' print?
Answer: The last field of each line, whatever the number of fields: NF is the count, so $NF is the last one.

4 Step by step

awk explained, then used in every field

All outputs were recorded on Ubuntu 24.04, where awk is mawk 1.3.4 (gawk is a separate package). The examples use features that work in both. Sample files: employees.csv, app.log, access.log.

awk '{print}' fields and print

🟢 Read-onlyno sudo

Splits each line into fields and prints the ones you choose. The default separator is any run of spaces or tabs; -F sets another. A comma in print $1, $2 inserts OFS (a space by default).

✓ Use it when
  • printing, reordering or reformatting columns
  • columns separated by a varying number of spaces (ps, ls -l, df, logs)
  • quick filters by a column value
✗ Don’t use it when
  • quoted CSV with commas inside fields (use gawk --csv, Python or csvkit)
  • simple fixed replacements (sed is shorter)

Syntax: awk [-F SEP] [-v OFS=SEP] '{print $N, …}' FILE

awkcommand-F,field separator'NR>1 {print $2, $5}'pattern { action }employees.csvfile

Always single-quote the program: $1 must reach awk, not be expanded by the shell.

'{print $1}'first fieldone column
'{print $2, $1}'reorderswap columns
'{print $NF}'last fieldany width
-F, / -F: / -F'\t'CSV / passwd / TSVseparators

awk '{print}' in system info / admin

  1. Situation: User names (the puzzle): /etc/passwd uses :, so tell awk.

    awk '{print $1}' /etc/passwd | head -2
echo ---
awk -F: '{print $1}' /etc/passwd | head -2
    root:x:0:0:root:/root:/bin/bash daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin --- root daemon

    Why this way: Without -F: the line has no spaces, so $1 is the whole line. -F: makes $1 the user name.

  2. Situation: Disk usage percentages from df (columns padded with spaces).

    awk 'NR>1 {print $6, $5}' df.txt
    / 69% /data 95% /dev/shm 0%

    Why this way: df.txt is saved df -P output (a real server would show its own disks). awk ignores how many spaces separate columns, so df, ps and ls -l output are easy to read.

awk '{print}' in web servers

  1. Situation: IP and status code from an access log.

    awk '{print $1, $9}' access.log | head -3
    185.220.101.4 401 103.21.44.7 200 10.0.0.5 200

    Why this way: The common log format splits on spaces: $1 IP, $7 URL, $9 status, $10 bytes.

awk '{print}' in data analysis / engineering

  1. Situation: Turn a space-separated file into CSV.

    printf 'Asha 91 Pune\nRavi 78 Agra\n' | awk -v OFS=, '{$1=$1} 1'
    Asha,91,Pune Ravi,78,Agra

    Why this way: $1=$1 forces awk to rebuild the line with OFS; the lone 1 is a true pattern that prints it.

Common mistake
✗awk '{print $1}' /etc/passwd | head -5 (“first field: usernames”)
✓awk -F: '{print $1}' /etc/passwd | head -5

The default separator is white space. /etc/passwd separates fields with :, so without -F: the whole line is field 1 (real run). That is the answer to the puzzle.

awk 'pattern' conditions

🟢 Read-onlyno sudo

A pattern without an action prints the matching lines. Patterns can be regexes, comparisons on fields, line numbers, ranges, and combinations.

✓ Use it when
  • rows that meet a condition on a column
  • filtering logs by level, status or time
  • data quality checks (wrong number of fields)
✗ Don’t use it when
  • simple text search in a whole line (grep is simpler)

awk 'pattern' in system info / admin

  1. Situation: Real users only (UID 1000 to 65533).

    awk -F: '$3>=1000 && $3<65534 {print $1, $3}' /etc/passwd | head -3
    ubuntu 1000 nixbld1 30001 nixbld2 30002

    Why this way: 65534 is the special user nobody; system accounts are below 1000.

  2. Situation: Filesystems more than 50% full.

    awk 'NR>1 && $5+0 > 50 {print $6, $5}' df.txt
    / 69% /data 95%

    Why this way: $5 is like “63%”; $5+0 turns it into the number 63 for the comparison.

awk 'pattern' in devops / cloud

  1. Situation: Problem lines in the log, any case (from your notes).

    awk 'tolower($0) ~ /error|fatal/ {print NR": "$4, $5, $6}' app.log
    4: db connection refused 6: db connection refused 8: payment timeout for 9: out of memory,

    Why this way: tolower makes the match case-insensitive in every awk (gawk also has IGNORECASE).

awk 'pattern' in testing / qa

  1. Situation: Find rows with the wrong number of columns before loading.

    printf 'a,b,c\nd,e\nf,g,h\ni,j,k,l\n' > in.csv
awk -F, 'NF != 3 {print "line " NR ": " NF " fields"}' in.csv
    line 2: 2 fields line 4: 4 fields

    Why this way: A fast data-quality gate: broken rows are reported with their line numbers.

awk 'pattern' in security

  1. Situation: Requests with status 401 to /admin.

    awk '$7 == "/admin" && $9 == 401 {print $1}' access.log | sort | uniq -c
    7 185.220.101.4

    Why this way: Two exact field conditions: more precise than grep on the whole line.

awk '… END {}' calculate and summarise

🟢 Read-onlyno sudo

Variables keep values across lines; arrays group by a key. BEGIN runs before reading (headers, settings), END after the last line (totals, averages).

✓ Use it when
  • totals, averages, counts, minimum and maximum
  • GROUP BY style summaries per key
  • reports with headers and footers
✗ Don’t use it when
  • very large group-bys or joins on huge data (use a database or Spark)

  1. Situation: Average salary per department (the story).

awk '… END {}' in data administration

  1. Situation: Slowest queries from a query log (time in column 2).

    printf 'q1 120\nq2 2400\nq3 35\nq4 980\n' > slow.log

  1. Situation: Mean and standard deviation of a numeric column.

    printf '4\n8\n6\n5\n7\n' > x.txt

    Why this way: Quick statistics on a column before reaching for Python (population standard deviation).

awk printf · functions in data analysis / engineering

  1. Situation: Clean a column: remove ₹ and commas from amounts, then add them.

    printf 'a,"₹1,250"\nb,"₹980"\n' > amt.csv
awk -F'"' '{gsub(/[^0-9]/, "", $2); s+=$2} END {print s}' amt.csv
    2230

    Why this way: Splitting on the quote character keeps the amount (with its comma) in field 2; gsub keeps only the digits.

awk printf · functions in software development

  1. Situation: Join two files on an ID, all in awk.

    printf '1,Asha\n2,Ravi\n' > names.csv; printf '1,Pune\n3,Goa\n' > city.csv
awk -F, 'NR==FNR {n[$1]=$2; next} ($1 in n) {print $1, n[$1], $2}' names.csv city.csv
    1 Asha Pune

    Why this way: While reading the first file (NR==FNR) store names; for the second file print matches. No sorting needed, unlike join.

awk printf · functions in devops / cloud

  1. Situation: Split a date field into parts.

    awk 'NR==1 {split($1, d, "-"); print "day", d[3], "month", d[2], "year", d[1]}' app.log
    day 06 month 11 year 2026

    Why this way: split fills an array; the return value is the number of parts.

Undo and safety net

awk only reads and prints; mistakes are in the output, not the files.

  • Wrong columns: check the separator: head -1 file | cat -A; use -F correctly.
  • Unsorted group output: for (k in a) has no order: pipe to sort.
  • Numbers like “63%” or “1,250”: convert: $5+0, gsub(/,/, "", $2).
  • Writing back to the file: awk has no -i (except gawk -i inplace): write to a new file and mv it (Lesson 5.2).

Error messages decoded

awk errors students see most. Each was really produced on our build machine (mawk), with its exit status.

  1. awk '{print $1' /etc/hostname
    awk: line 2: missing } near end of file exit status: 2

    What it means: A missing closing brace: syntax error.

    Fix: Balance { } and quotes: '{print $1}'.

  2. echo "a b" | awk "{print $1}"
    a b exit status: 0

    What it means: Double quotes: the shell replaced $1 with an empty string, so awk printed whole lines. No error, wrong result.

    Fix: Use single quotes around awk programs.

  3. awk -F, '{print $2}' /nope.csv
    awk: cannot open "/nope.csv" (No such file or directory) exit status: 2

    What it means: The input file does not exist.

    Fix: Check the path.

  4. echo 5 | awk '{print $1/0}'
    inf exit status: 0

    What it means: Not an error in mawk: it silently prints inf (gawk stops with “division by zero attempted”). Either way the report is wrong.

    Fix: Check the divisor: n ? s/n : 0.

Quick check Why must totals be printed in END and not in the main block?
Answer: The main block runs once per line; the total is only complete after the last line, which is exactly when END runs.

NR > 1 && ($4 == "Pune" || $4 == "Mumbai") { sum[$3] += $5; n[$3]++; total += $5; c++ }
END {
  for (d in sum) printf "%-12s %5d %10.0f\n", d, n[d], sum[d] / n[d]
  printf "%-12s %5d %10.0f\n", "ALL", c, total / c
}

Puzzle answer Remember the question from the story? Open to check your guess.

awk’s default separator is white space. Lines in /etc/passwd contain no spaces (they use :), so the whole line is field 1. The fix is one option: -F:. Then awk -F: '{print $1}' /etc/passwd prints the user names.

Quick check How do you print the number of fields on each line of a CSV?
Answer: awk -F, '{print NF}' file

Quick revision

Lesson 6.5 in one screen

  • awk 'pattern {action}' file; no pattern = all lines, no action = print.
  • Fields $1…$NF, $0; -F, -F:; default FS = runs of blanks; -v OFS=,.

Interview and viva questions

How do I print a specific column with awk?

awk '{print $3}' file (add -F, for CSV, -F: for /etc/passwd).

How do I sum a column with awk?

awk '{s+=$2} END {print s}' file.

How do I filter rows by a column value?

awk -F, '$3 == "HR"' file or awk '$5 > 100' file.

What is the difference between awk, sed and grep?

grep finds lines, sed edits lines, awk works with columns, conditions and calculations.

How do I group by a column in awk?

awk '{s[$1]+=$2} END {for (k in s) print k, s[k]}' file | sort.

How do I use a shell variable in awk?

awk -v lim="$limit" '$2 > lim' file.

Why does awk print whole lines instead of a column?

The separator is wrong: set -F to the real delimiter (for example -F: for /etc/passwd).
