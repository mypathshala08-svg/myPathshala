2 Definition

date, cal, bc, seq, sleep, time and watch

Formal definition (write this in exams)

date prints the current or a given date and time in any format, converts between formats and time zones, and (as root) sets the system clock. cal displays a calendar. bc (basic calculator) is an arbitrary-precision calculator language. seq prints a sequence of numbers. sleep pauses for a given time. time reports how long a command took. watch runs a command repeatedly and shows its output full-screen.

In simple words

Clock, calendar, calculator, counter, timer, stopwatch and a screen that refreshes itself.

Everyday utilities at four depths

Pick your depth. Completely new? Start at Very basic and climb one step at a time.

Very basic No jargon: the office desk

Think of the things on an office desk.

  • date is the clock, cal the wall calendar, bc the calculator.
  • seq stamps numbers one after another; sleep waits; time is a stopwatch.
  • watch is like a CCTV screen: it shows the same view again every few seconds.

Basic The commands you will type every day

  • date now; date +%F = 2026-11-06; date '+%d-%m-%Y' = 06-11-2026.
  • cal this month, cal 2026 the whole year.
  • echo '2+3*4' | bc = 14; with decimals: echo 'scale=2; 10/3' | bc = 3.33.
  • seq 5 prints 1–5, one per line; seq 2 2 10 = 2 4 6 8 10.
  • sleep 5 waits 5 seconds; time cmd measures; watch -n 2 ls repeats ls every 2 s (Ctrl+C stops).

Intermediate Formats, arithmetic and the traps

  • Format codes: %Y %m %d %H %M %S, %F = %Y-%m-%d, %T = %H:%M:%S, %A %B names, %s Unix time. Capital M is minutes, lower m is month.
  • date -d understands “+45 days”, “yesterday”, “next monday”, “2026-11-06 -30 days”, “@1793941200”.
  • bc’s scale = digits after the point, applied at every step: use a high scale for money and powers, round at the end. bc -l sets scale 20 and adds sqrt, sine, log.
  • seq -w pads to equal width, -s, joins with commas, -f "file_%03g.txt" formats each number.
  • time reports real (wall clock), user and sys (CPU time in your code / in the kernel).

Advanced Behind the screen: clocks and time zones

  • Linux keeps time as seconds since 1 Jan 1970 00:00 UTC (the Unix epoch). Time zones are only applied when printing: TZ=Asia/Kolkata reads rules from /usr/share/zoneinfo.
  • Setting the clock (sudo date -s) changes the system clock; servers use NTP instead (timedatectl, chrony, Lesson 16.7) because a wrong clock breaks logs, TLS certificates and Kerberos.
  • 32-bit signed timestamps overflow on 19 January 2038 (the “Y2038 problem”); 64-bit Linux uses 64-bit time.
  • time in bash is a keyword (it can time a whole pipeline; TIMEFORMAT changes its output); /usr/bin/time -v is a separate program that also reports memory (install the time package).
  • sleep uses the kernel’s high-resolution timers (clock_nanosleep), so sleep 0.2 works.

Did you know? India uses one time zone for the whole country, IST (UTC+05:30), a half-hour offset. In Linux it is called Asia/Kolkata; older systems used Asia/Calcutta, which still works as an alias, because time zone names follow city names, not countries.

Exam tip: “How do you print the date as YYYY-MM-DD and get yesterday’s date?” → date +%F (or +%Y-%m-%d); date -d yesterday +%F; mention %M is minutes and %m is month, date -s to set the time (root), and NTP for servers.

Quick check What does date +%Y-%M-%D print, and what should it be?
Answer: It mixes up codes: %M is minutes and %D is mm/dd/yy (a real run printed 2026-30-11/06/26). Use +%Y-%m-%d or simply +%F.

date date and time

🟢 Read-onlyno sudo

Prints the date and time now, or any date you give with -d, in any format after a +. As root it can set the clock.

✓ Use it when
  • file and folder names with dates
  • log lines, reports, deadlines
  • converting time zones and Unix timestamps
✗ Don’t use it when
  • measuring how long something takes (use time)
  • setting the clock on servers (use NTP / timedatectl)

Syntax: date [-d 'DATE'] [-u] [+FORMAT] · sudo date -s 'DATE'

datecommand-d '+45 days'which date'+%d-%m-%Y'format (starts with +)

The format must start with +; quote it when it contains spaces.

date in system info / admin

  1. Situation: Name a backup file with today’s date and time (sortable).

    touch "backup_$(date +%F_%H%M).tar.gz" && ls backup_* | sed -E "s/[0-9]{4}\.tar/HHMM.tar/"
    backup_2026-11-06_HHMM.tar.gz

    Why this way: %F_%H%M sorts correctly by name. (The time part is masked here because it changes every run.)

  2. Situation: What time is it on the UTC server log vs in India?

    d='2026-11-06 10:30:00'
date -d "$d" '+%F %T %Z'
date -u -d "$d IST" '+%F %T %Z'
    2026-11-06 10:30:00 IST 2026-11-06 05:00:00 UTC

    Why this way: The same moment: 10:30 in India is 05:00 UTC. Note $d IST: without a zone, date -u -d would read 10:30 itself as UTC. Servers usually log in UTC; always check which one a log uses.

date in data analysis / engineering

  1. Situation: The date 30 days before a report date, for a WHERE clause.

    date -d '2026-11-06 -30 days' +%F
    2026-10-07

    Why this way: date does the calendar arithmetic (month lengths, leap years) for you.

  2. Situation: How many days until a deadline?

    echo $(( ( $(date -d 2026-12-25 +%s) - $(date -d 2026-11-06 +%s) ) / 86400 )) days
    49 days

    Why this way: Convert both to seconds (%s), subtract, divide by 86,400 seconds per day.

date in software development

  1. Situation: Convert a Unix timestamp from an API or database into a readable date.

    date -d @1793941200
date -u -d @1793941200 --iso-8601=seconds
    Fri Nov 6 10:30:00 IST 2026 2026-11-06T05:00:00+00:00

    Why this way: @ means “seconds since 1970”. APIs often use these; ISO 8601 is the standard text form.

date in devops / cloud

  1. Situation: A meeting at 10:30 IST: what time is it for the team in New York and London?

    d='2026-11-06 10:30:00'
TZ=America/New_York date -d "$d IST" '+%F %T %Z'
TZ=Europe/London date -d "$d IST" '+%F %T %Z'
    2026-11-06 00:00:00 EST 2026-11-06 05:00:00 GMT

    Why this way: TZ changes the zone just for this command. (Summer time changes these offsets; date knows the rules.)

date in data administration

  1. Situation: When was this dump last modified?

    touch -d '2026-11-05 23:00' night.sql
date -r night.sql '+%F %T'
    2026-11-05 23:00:00

    Why this way: -r reads a file’s modification time: quick check that last night’s backup really ran.

date in testing / qa

  1. Situation: Validate dates in test data: is 30 February a real date?

    date -d '2026-02-30' +%F 2>&1; date -d '2028-02-29' +%F
    date: invalid date ‘2026-02-30’ 2028-02-29

    Why this way: date rejects impossible dates and knows leap years (2028 is one).

Common mistake
✗date -d '2026-11-06 10:30:00 +45 days'
✓date -d '2026-11-06 +45 days' (or date -d '+45 days' for today)

After a time, +45 is read as a time zone offset, so a real run fails with “invalid date”. Leave out the time, or write “45 days” after it.

bc basic calculator

🟢 Read-onlyno sudo

A calculator language: give it an expression (usually through echo … |) and it prints the result. It is exact with any number of digits; scale sets the digits after the decimal point.

✓ Use it when
  • decimals: money, percentages, averages
  • powers, square roots, number bases
  • quick calculations at the terminal or in scripts
✗ Don’t use it when
  • whole numbers only (bash $(( )) is enough and faster)
  • big data sets (use awk, Python or a database)

Syntax: echo 'EXPRESSION' | bc [-l]

OptionWhat it doesWhen to use it
+ - * / % ^add, subtract, multiply, divide, remainder, powerany calculation
scale=NN digits after the point (default 0)money: scale=2 at the end
-lmath library: scale 20, s() c() a() l() e()sqrt, log, trigonometry
sqrt(x)square rootstatistics
obase=2 / ibase=16output / input number basebinary, hex
a > bcomparisons give 1 (true) or 0decimal tests in scripts
bc -qinteractive, no banner; quit to exita calculator session

bc in data analysis / engineering

  1. Situation: Average marks of a class, with two decimals.

    echo 'scale=2; (91+78+85+66)/4' | bc
    80.00

    Why this way: Integer arithmetic would give 80 and hide the .00 vs .75 difference.

bc in data administration

  1. Situation: Convert 734003200 bytes into GB for a report.

    echo 'scale=2; 734003200/1024^3' | bc
    .68

    Why this way: 1 GiB = 1024³ bytes. 0.68 GB.

bc in software development

  1. Situation: Convert numbers between decimal, binary and hex.

    echo 'obase=2; 10' | bc
echo 'ibase=16; FF' | bc
echo 'obase=16; 255' | bc
    1010 255 FF

    Why this way: Handy for permissions, bit masks and colours. Set obase before ibase if you change both.

bc in ml / ai

  1. Situation: Square root for a standard deviation step.

    echo 'sqrt(2)' | bc -l
echo 'scale=4; sqrt(2)' | bc -l
    1.41421356237309504880 1.4142

    Why this way: -l loads the math library and sets scale 20; reset scale for shorter output.

bc in devops / cloud

  1. Situation: Alert if CPU load (a decimal) is above 1.5; bash [ ] cannot compare decimals.

    load=1.82
if [ "$(echo "$load > 1.5" | bc)" -eq 1 ]; then echo "ALERT: load $load"; fi
    ALERT: load 1.82

    Why this way: bc prints 1 for true. bash [ 1.82 -gt 1.5 ] would fail with “integer expression expected”.

bc in testing / qa

  1. Situation: Compound interest: why scale must be high during the calculation.

    echo 'scale=2; 100000*1.07^5' | bc
echo 'scale=10; 100000*1.07^5' | bc
    140000.00 140255.1730700000

    Why this way: bc cuts to scale digits at every multiplication of the power, so scale=2 loses money. Calculate with a high scale, round only for display.

Common mistake
✗echo 'scale=2; 100000*1.07^5' | bc → 140000.00
✓echo 'scale=10; 100000*1.07^5' | bc → 140255.1730700000

scale is applied to intermediate results too. For money: high scale while calculating, round at the end (for example with printf "%.2f").

seq sequence

🟢 Read-onlyno sudo

Prints numbers from a start to an end, one per line, with an optional step. Unlike braces, the limits can come from variables.

✓ Use it when
  • numbers for loops, file names and test data
  • steps (every 5th), countdowns, decimals
  • padding and formats: 001, file_007.txt
✗ Don’t use it when
  • a fixed, small range typed by hand (braces {1..10} are simpler)
  • the end comes from a variable and you use braces ({1..$n} does not work; seq does)

seq in testing / qa

  1. Situation: Create 3 numbered test files with a format.

    for f in $(seq -f "user_%03g.json" 1 3); do touch "$f"; done; ls
    user_001.json user_002.json user_003.json

    Why this way: -f with %03g gives 001, 002, 003 inside any name.

seq in devops / cloud

  1. Situation: Retry a command up to 3 times (the count comes from a variable).

    max=3
for i in $(seq 1 "$max"); do echo "attempt $i"; done
    attempt 1 attempt 2 attempt 3

    Why this way: {1..$max} would not work, because braces are expanded before variables. seq has no such problem.

seq in data analysis / engineering

  1. Situation: A test file with 100,000 rows to check a pipeline’s speed.

    seq 1 100000 > ids.txt && wc -l ids.txt && tail -n 1 ids.txt
    100000 ids.txt 100000

    Why this way: seq generates huge sequences in a fraction of a second.

seq in system info / admin

  1. Situation: Ping a range of server numbers (names app01–app03).

    seq -w 1 3 | tr "\n" " "; echo
for n in $(seq -f "app%02g" 1 3); do echo "checking $n"; done
    1 2 3 checking app01 checking app02 checking app03

    Why this way: Careful: seq -w pads only to the width of the largest number, so 1 to 3 stays 1 2 3. -f "app%02g" forces two digits: app01.

sleep · time · watch in software development

  1. Situation: Which of two ways is faster?

    TIMEFORMAT='%R s'
time (seq 1 300000 | wc -l)

    300000 0.007 s 0.039 s

Undo and safety net

These tools only read and print, with two exceptions.

  • sudo date -s changed the clock: on Ubuntu with time sync on, run sudo timedatectl set-ntp true (or restart chrony/systemd-timesyncd) to get the correct time back.
  • watch or sleep is still running: Ctrl+C stops it.
  • bc is waiting for input: you ran bc without echo: type quit or press Ctrl+D.
  • A typo in a format: nothing is changed; print again. Always test formats before using them in file names.

Error messages decoded

The errors students see most with these tools. Each was really produced on our build machine, with its exit status.

  1. date -d '2026-11-06 10:30:00 +45 days'
    date: invalid date ‘2026-11-06 10:30:00 +45 days’ exit status: 1

    What it means: +45 after a time is read as a time zone.

    Fix: date -d '2026-11-06 +45 days'.

  2. date -d '2026-02-30'
    date: invalid date ‘2026-02-30’ exit status: 1

    What it means: 30 February does not exist.

    Fix: Check the date; date validates it for you.

  3. date +%F %T
    date: extra operand ‘%T’ Try 'date --help' for more information. exit status: 1

    What it means: The space split the format: %T became a second argument, which date reads as a date to set.

    Fix: Quote it: date '+%F %T'.

  4. [ 1.82 -gt 1.5 ] && echo high
    /home/riya/script.sh: line 1: [: 1.82: integer expression expected exit status: 2

    What it means: bash test (and $(( ))) works with whole numbers only.

    Fix: [ "$(echo "1.82 > 1.5" | bc)" -eq 1 ].

  5. echo '10 / 0' | bc
    Runtime error (func=(main), adr=6): Divide by zero exit status: 0

    What it means: Division by zero. Note that bc still exits with status 0, so a script will not notice.

    Fix: Check the divisor before calculating, or check bc’s output.

  6. timeout 1 sleep 5
    exit status: 124

    What it means: timeout stopped sleep after 1 s; exit status 124 means “timed out”.

    Fix: Not an error in your code: use the 124 in scripts to detect timeouts.

Script it: wait-for-file.sh

A reusable “wait until a file appears” script with a timeout, a timestamped log line and the time it took.

#!/bin/bash
file=${1:-ready.flag}; limit=${2:-5}
(sleep 0.6; touch "$file") &                 # demo: something creates the file
start=$(date +%s)
until [ -e "$file" ]; do
  if [ $(( $(date +%s) - start )) -ge "$limit" ]; then
    echo "gave up after ${limit}s" >&2; exit 1
  fi
  sleep 0.2
done
echo "$file appeared after about $(( $(date +%s) - start ))s"
ready.flag appeared after about 0s

The real script would also print $(date '+%F %T') in front of each message for the log.

Puzzle answer Remember the question from the story? Open to check your guess.

bc is right about what it was told to do, but 140255.17 is the correct amount. scale=2 is applied to every intermediate result: 1.07² = 1.1449 is cut to 1.14, and so on through the power, so money is lost at each step. Calculate with a higher scale (scale=10 gives 140255.1730700000) and round only at the end.

Interview and viva questions

How do you display the date in YYYY-MM-DD format?

date +%F (same as date +%Y-%m-%d).

How do you get yesterday’s date in Linux?

date -d yesterday +%F (GNU date).

How do you do decimal calculations in the shell?

With bc: echo 'scale=2; 10/3' | bc. bash $(( )) only handles integers.

What is the difference between real, user and sys in time?

real is elapsed wall-clock time; user is CPU time in the program; sys is CPU time in the kernel for it.

How do you run a command every few seconds?

watch -n SECONDS command (interactive), or a loop with sleep in scripts.

What is seq used for?

Printing number sequences for loops, file names and test data, with steps, padding (-w) and formats (-f).

How do you set the system date?

sudo date -s 'YYYY-MM-DD HH:MM:SS' (or timedatectl set-time); on servers use NTP instead.

  1. bash tests and $(( )) are integer-only.
  2. Use bc: [ "$(echo "$load > 2" | bc)" -eq 1 ], or awk.
  3. Test the alert path with a fake high value.

Avoid: cutting the decimals off and hoping.

Global team · DevOpsMid-level

Logs that do not line up

Servers in Mumbai and Frankfurt log local time; incident timelines are confusing, and once a year an hour repeats.

The interviewer is checking: do you understand time zones?

Show a strong answer
  • Log in UTC everywhere (date -u, ISO 8601 with offset), convert only for display.
  • Europe has daylight saving: local time repeats an hour in autumn; IST does not change.
  • Keep clocks synced with NTP (timedatectl, chrony).

Avoid: “we will add 3.5 hours by hand”.

Platform · reliabilitySenior

The deploy that hung for six hours

A pipeline waits for a health file with while [ ! -e ok ]; do sleep 5; done; the service never started.

The interviewer is checking: do you design waits with limits?

Show a strong answer
  • Every wait needs a deadline: timeout 300 bash -c 'until …; do sleep 5; done' and handle exit 124.
  • Back-off for retries; log timestamps; fail fast with a clear message.
  • Measure normal start time with time to choose the limit.

Avoid: removing the check so the pipeline “passes”.

Interview and certification corner

Print today’s date as DD-MM-YYYY.
date '+%d-%m-%Y'.
Difference between %m and %M?
%m is the month (01–12); %M is minutes (00–59).
How do you convert a Unix timestamp to a date?
date -d @TIMESTAMP (GNU).
Why does echo 10/3 | bc print 3?
scale is 0 by default; set scale=2 for decimals.
How do you run a command every 5 seconds and highlight changes?
watch -n 5 -d command.
What do real, user and sys mean?
Elapsed time; CPU time in user space; CPU time in the kernel.
How do you stop a command that runs too long?
timeout SECONDS command (exit status 124 when it times out).
Where this appears in certification exams
  • RHCSA (EX200): “Configure time service clients” (chrony, timedatectl) and essential command-line tools.
  • LFCS: Operations: maintain system time (NTP, time zones) and use shell utilities in scripts.
  • CompTIA Linux+: Time and date management (date, timedatectl, NTP) and basic shell utilities.
