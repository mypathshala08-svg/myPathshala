2 Definition

rename and regular expressions

Formal definition (write this in exams)

rename (Perl rename, Debian and Ubuntu) renames the given files by applying a Perl expression, usually a substitution s/REGEX/REPLACEMENT/FLAGS or a transliteration y/FROM/TO/, to each file name. A regular expression (regex) is a pattern language that describes text by position (^ $ \b), character sets ([ ] \d \w \s), repetition (* + ? {n,m}) and groups (( ), referenced as $1).

In simple words

rename = find and replace in many file names at once; -n previews.

Bulk renaming at four depths

Pick your depth. Completely new? Start at Very basic and climb one step at a time.

Very basic No jargon: find and replace for file names

You know Find and Replace from Word or Excel.

  • rename does the same with file names: find a piece of the name and replace it.
  • It works on many files at once: all photos, all reports.
  • The -n option is the preview: it shows the new names and changes nothing.

Basic The commands you will type every day

  • rename -n 's/old/new/' files: preview. Remove -n to do it; add -v to see each rename.
  • s/draft/final/ replaces the first “draft” in each name; add g at the end for every match.
  • ^ = start of the name, $ = end: s/^/2026_/ adds a prefix, s/\.txt$/.md/ changes the extension.
  • y/A-Z/a-z/ turns capitals into small letters.
  • Install on Ubuntu/Debian: sudo apt install rename.

Intermediate Regular expression building blocks

  • . any character, so a real dot is \..
  • How many: * 0 or more, + 1 or more, ? 0 or 1, {2,4} 2 to 4.
  • Classes: [abc], [0-9], [^a-z] (not); shortcuts \d digit, \w letter/digit/_, \s space; capitals mean “not”: \D \W \S.
  • \b word boundary, \B not a boundary. Note: _ counts as a word character.
  • Groups ( ) remember text; use it in the replacement as $1, $2. Flags: g all, i ignore case.

Advanced Behind the screen: Perl, quotes and two different renames

  • Ubuntu’s rename (package rename, also called file-rename/prename) is a Perl program: for each file it puts the name in Perl’s $_, runs your code, and calls rename() if the name changed. Any Perl works: s///, y///, lc, even sprintf.
  • It does not overwrite an existing file unless you add -f; it prints “not renamed: … already exists”.
  • Single quotes give the code to Perl unchanged (best). Inside single quotes $(date) is not run by bash; Perl reads $( as its own variable (your group IDs). For bash values use double quotes and escape Perl’s own \$1.
  • RHEL, Rocky and Fedora ship util-linux rename with a different syntax: rename FROM TO files (plain text, no regex). Check with rename --version.
  • Non-ASCII names (é, हिन्दी) are bytes for Perl unless you add -u / utf8 handling: \w may not match them.

Did you know? Regular expressions were invented by the mathematician Stephen Kleene in 1951 to describe “regular events”. Ken Thompson put them into the Unix editor ed in 1968, and the command g/re/p (global, regular expression, print) became the name of grep.

Exam tip: “Difference between mv and rename” → mv renames or moves one file (or moves many into a folder) and uses no patterns; rename changes many names at once with a Perl substitution, does not move files to other folders, previews with -n, and on RHEL uses a different util-linux syntax.

Quick check What does rename 's/^/2026_/' *.csv do?
Answer: Adds “2026_” at the start of every .csv name: ^ is the start, and replacing “the start” inserts text there.

Common mistake
✗rename 's/.txt/.md/' * (dot not escaped, no anchor)

An unescaped . matches any character, and without $ the first “?txt” anywhere in the name is replaced, e.g. in my_txt_notes.txt.

Quick check Glob or regex? In a glob, *.txt means “anything ending in .txt”. What does * mean in a regex?
Answer: “0 or more of the previous item”. The regex for “anything” is .*.

rename Perl rename

🟡 Changes filesno sudo

Applies a Perl expression to each file name and renames the file if the name changed. Use -n first: it prints rename(old, new) for each file and changes nothing.

✓ Use it when
  • the same change on many names: extension, prefix, spaces, case

  • you want a preview of every change (-n)
✗ Don’t use it when

  • moving files into other folders (mv, Lesson 3.2)

regex in data analysis / engineering

  1. Situation: Remove all digits from names.

    Typical output on Ubuntu (rename package) · result verified with the same Perl expression

    touch data123.csv v2_report.csv

    Why this way: \d+ = a run of digits; g removes every run.

  2. Situation: Keep only the digits (careful!).

    Typical output on Ubuntu (rename package) · result verified with the same Perl expression

    touch file123name.txt report_2024_version.txt log-07.txt

ls

    Why this way: \D also matches the dot and “txt”, so the extension disappears: 123, 2024, 07. A common classroom example shows “123.txt”; that is not what really happens.

regex in software development

  1. Situation: Whole word only: prefix files that contain the word “report”.

    Typical output on Ubuntu (rename package) · result verified with the same Perl expression

  2. Situation: Inside a word only: \B (not a boundary).

  1. Situation: Remove every non-word character (dots too!).

    Typical output on Ubuntu (rename package) · result verified with the same Perl expression

regex in security

  1. Situation: Names with accents or Indian scripts: \w does not match them by default.

    Typical output on Ubuntu (rename package) · result verified with the same Perl expression

    touch 'Résumé (final).pdf'
rename -v 's/[^\w.-]+/_/g' *
ls
    Résumé (final).pdf renamed as R_sum_final_.pdf R_sum_final_.pdf

    Why this way: Perl sees é as two bytes that are not \w, so “Résumé” becomes “R_sum”. Decide on purpose whether to keep Unicode names (Perl’s utf8 options) or transliterate them.

Common mistake
✗rename 's/^(.*)\.txt$/$1_$(date +%Y-%m-%d).txt/' *.txt
✓rename "s/\\.txt\$/_$(date +%F).txt/" *.txt

In single quotes bash never runs $(date …); Perl reads $( as its own variable (the group IDs), so the name becomes something like report_30033 30033date +%Y-%m-%d).txt (verified). Use double quotes so bash inserts the date, and escape Perl’s $ as \$.

y/// · util-linux rename case changes and the Red Hat rename

🟡 Changes filesno sudo

y/abc/xyz/ (or tr) replaces characters one for one: a→x, b→y, c→z. On RHEL, Rocky and Fedora, rename is a different program from util-linux: rename FROM TO FILES, plain text only.

✓ Use it when

✗ Don’t use it when

Undo and safety net

If a bulk rename went wrong…

  • Before: always -n first, and read every line. Then the same command without -n.
  • Reverse a simple change: swap the parts: s/\.md$/.txt/ undoes s/\.txt$/.md/.
  • Log what you did: run with -v and save it: rename -v … | tee rename.log; each line tells you the old name.
  • Two names became one: rename refuses (no overwrite) and reports it; never add -f unless you are sure.
  • Big jobs: copy the folder first (cp -a photos photos.bak), rename the copy, check, then swap.

Error messages decoded

The errors and traps students hit with rename. Messages from the rename program itself are typical; the name results were verified.

  1. rename 's/a/b/' x.txt
    /home/riya/script.sh: line 1: rename: command not found exit status: 127

    What it means: On our build machine rename is not installed: the same message appears on minimal Ubuntu systems.

    Fix: sudo apt install rename (Ubuntu/Debian).

  2. echo 'invoice(final).pdf' | perl -lpe 's/(/_/'
    Unmatched ( in regex; marked by <-- HERE in m/( <-- HERE / at -e line 1. exit status: 255

    What it means: ( starts a group in a regex; alone it is a syntax error. (Tested with perl -lpe, the same engine rename uses.)

    Fix: Escape special characters: s/\(/_/. Special: . * + ? ( ) [ ] { } ^ $ | \ /.

  3. echo 'a.b.txt' | perl -lpe 's/./_/g'
    _______ exit status: 0

    What it means: Not an error message, but a classic mistake: an unescaped . matches every character.

    Fix: s/\./_/g replaces only real dots.

Script it: clean-names.sh

A portable clean-up that works on Ubuntu and RHEL alike, because it uses only bash and mv: lowercase, spaces to underscores, unsafe characters removed, and a dry-run mode.

#!/bin/bash
# clean-names.sh [-n]: lowercase, spaces -> _, only [a-z0-9._-]
dry=0; [ "$1" = "-n" ] && dry=1
touch 'IMG 0001.JPEG' 'Invoice (Final).PDF' 'ok_name.txt'   # demo files
for f in *; do
  [ -f "$f" ] || continue
  [ "$f" = "$(basename "$0")" ] && continue
  new=${f,,}                  # lowercase
  new=${new// /_}             # spaces to _
  new=${new//[^a-z0-9._-]/}   # drop anything else
  [ "$f" = "$new" ] && continue
  if [ -e "$new" ]; then echo "skip: $new exists"; continue; fi
  if [ $dry -eq 1 ]; then echo "would rename: $f -> $new"; else mv -- "$f" "$new" && echo "renamed: $f -> $new"; fi
done
renamed: IMG 0001.JPEG -> img_0001.jpeg renamed: Invoice (Final).PDF -> invoice_final.pdf

Run it with -n first, exactly like rename. The ${var//pattern/} forms use globs, not regex: [^a-z0-9._-] is a bracket expression (Lesson 3.4).

Puzzle answer Remember the question from the story? Open to check your guess.

The expression was in single quotes, so bash did not run $(date +%F); it was passed to Perl as text. In Perl, $( is a built-in variable holding your group IDs, so Perl inserted those numbers followed by “date +%F)”. Fix: use double quotes so bash inserts the date first, and escape Perl’s own symbols: rename "s/\\.txt\$/_$(date +%F).txt/" *.txt. And always preview with -n.

Answer: rename -n 's/ /_/g' *

Interview and viva questions

How do you rename multiple files at once in Linux?

With rename and a Perl expression, e.g. rename 's/\.txt$/.md/' *.txt, or with a bash loop and mv.

What is the difference between mv and rename?

mv renames or moves one file at a time without patterns; rename changes many names with a regex and does not move files between folders.

How do you preview a rename?

rename -n prints the planned changes without renaming anything.

How do you replace spaces in file names?

rename 's/\s+/_/g' * (or a loop with ${f// /_}).

How do you convert file names to lowercase?

rename 'y/A-Z/a-z/' * (or a loop with ${f,,}).

Why does rename behave differently on CentOS/RHEL?

Those systems ship util-linux rename (rename FROM TO files), not the Perl version.

Is a glob the same as a regex?

No. Globs choose files (*.txt); regex describes text inside the expression (.*\.txt$).

It is the util-linux version with syntax rename FROM TO files.

  • RHCSA (EX200): Essential tools: “Use grep and regular expressions to analyze text”; the same regex skills apply to renaming.
  • LFCS: Essential Commands: use regular expressions and shell tools to manage files.
  • CompTIA Linux+: Regular expressions and bulk file operations in file management and scripting objectives.
