Managing groups: groupadd, gpasswd and usermod -aG

Groups give the same access to many people at once. This lesson explains groupadd, groupmod, groupdel, usermod -aG and gpasswd, the difference between adding and replacing, and how admins, DevOps, data teams and security use groups every day.

The problem

Friday 6 p.m.: a developer asks to be added to the docker group. The admin types sudo usermod -G docker riya, leaves for the weekend, and on Monday Riya cannot use sudo, cannot read the shared folder and cannot deploy. One missing letter, -a, removed every other group. Groups are how Linux gives the same access to many people at once; managing them is simple, but you must know which commands add, which replace and when the change takes effect.

By the end of this page you will be able to:

  • create, rename, renumber and delete groups with groupadd, groupmod and groupdel
  • add and remove members safely with usermod -aG, gpasswd -a/-d/-M and group admins (gpasswd -A)
  • build a shared project folder for a team, and make new group membership take effect (newgrp, re-login)

2 Definition

groupadd, groupmod, groupdel, gpasswd and usermod -aG

Formal definition (write this in exams)

A group is a named set of users with a GID, used to give several users the same access. groupadd creates a group, groupmod renames or renumbers it, and groupdel deletes it. Membership is changed with usermod -aG (append groups to a user) or gpasswd (add, remove or set members of a group). All need root, except gpasswd for a group’s administrators.

In simple words

Give access to a team once, then manage people by changing who is in the group.

Groups at four depths

Pick your depth. Completely new? Start at Very basic and climb one step at a time.

Very basic No jargon: team badges

A group is a team badge.

Basic The commands you will type

  • sudo groupadd developers: a new team.
  • sudo usermod -aG developers aman: give Aman the badge (keep his others).
  • sudo gpasswd -d aman developers: take it back.
  • getent group developers: who has it.

Intermediate Primary vs supplementary, and when changes apply

  • Primary group (passwd field 4): one per user, becomes the group of new files. Change with usermod -g.
  • Supplementary groups (members in /etc/group): extra access. -G sets the whole list, -aG adds to it.
  • gpasswd edits one membership at a time: -a add, -d delete, -M set all members, -A set group administrators who can then add/remove members without sudo.
  • A running session keeps the groups it logged in with. New membership: log out and in, newgrp GROUP (a new shell with that group), or su - $USER.

Advanced Behind the screen: GIDs, gshadow and limits

  • Files store only the GID. groupmod -n (rename) changes nothing on disk; groupmod -g (renumber) leaves existing files with the old number: fix them with find / -gid OLD -exec chgrp NEW {} +.
  • /etc/gshadow holds group administrators and (rarely used) group passwords: name:password:admins:members.
  • groupdel refuses to delete any user’s primary group. Files owned by a deleted group keep the bare GID.
  • The kernel keeps a process’s supplementary groups (up to 65536) in its credentials; NFSv3 with AUTH_SYS sends at most 16, a classic cause of “works locally, denied on NFS”.
  • Some groups are powerful: sudo/wheel (root via sudo), docker and lxd (root-equivalent), adm (read logs), disk (raw disks). Audit them.

Did you know? The name wheel for the admin group comes from 1970s slang “big wheel” (an important person). Fedora and RHEL still use it; Ubuntu calls it sudo.

Exam tip: “Add user tom to the group wheel without removing his other groups.” → usermod -aG wheel tom (or gpasswd -a tom wheel). Check with id tom.

Quick check Why give a folder to a group instead of to each user?
Answer: You change access in one place (the member list) instead of on every folder, and nobody else gets access.
Common mistake
✗“To remove a user from a group: sudo nano /etc/group”
✓Use <code>sudo gpasswd -d USER GROUP</code>. If you must edit, use <code>sudo vigr</code> (and <code>sudo vigr -s</code> for gshadow), which locks the file and checks it.

nano does not lock the file and does not update /etc/gshadow; a typo can break every group lookup. gpasswd -d is the recommended way, as the notes also say.

groupadd · groupmod · groupdel create, change, delete groups

🟡 Changes filessudo needed

groupadd adds a line to /etc/group and /etc/gshadow. groupmod renames (-n) or renumbers (-g) it. groupdel removes it, unless it is someone’s primary group.

✓ Use it when
  • a new team, project or role
  • a fixed GID that must match on every server
  • scripts that create a group only if missing
✗ Don’t use it when
  • one group per person for shared access (use one team group)

Syntax: sudo groupadd [-g GID] [-r] [-f] NAME · sudo groupmod [-n NEW] [-g GID] NAME · sudo groupdel NAME

usermod -aG · usermod -g add groups to a user

🟡 Changes filessudo needed

✗ Don’t use it when

Common mistake
✗sudo usermod -G docker riya

Without -a the user loses every other supplementary group, including sudo. If it happened to you, ask another admin, or use recovery mode, and re-add with -aG.

gpasswd manage members of a group

🟡 Changes filessudo needed

Works from the group’s point of view: -a adds a user, -d removes one, -M sets the full member list, -A sets group administrators, who may then run gpasswd -a/-d on that group without sudo.

✓ Use it when

  • setting a group’s exact members
  • letting a team lead manage membership
✗ Don’t use it when
  • -M when you meant to add one person

newgrp · id · su - make a new group take effect

🟢 Read-onlyno sudo

Groups are loaded when a session starts. newgrp GROUP starts a new shell whose primary group is GROUP (only if you are a member). su - $USER or logging in again loads the full new list.

✓ Use it when
  • using a group you were just added to, without logging out
  • checking a membership change
✗ Don’t use it when
  • scripts (newgrp starts an interactive shell)

Undo and safety net

Group changes are reversible, except deleting data or renumbering carelessly.

  • Lost groups with usermod -G: add them back with usermod -aG a,b,c; old list in /etc/group- (backup).
  • Removed the wrong member: gpasswd -a USER GROUP.
  • Deleted a group by mistake: recreate it with the same GID (groupadd -g N): files come back to it.
  • Renumbered a group: find / -xdev -gid OLD -exec chgrp NEW {} +.

Error messages decoded

Errors students see most. Each was really produced on our build machine, with its exit status.

  1. sudo groupadd finance
    groupadd: group 'finance' already exists exit status: 9

    What it means: The group already exists (exit 9).

    Fix: Use it, or groupadd -f in scripts.

  2. sudo gpasswd -a aman nosuchgroup
    gpasswd: group 'nosuchgroup' does not exist in /etc/group exit status: 3

    What it means: No such group (exit 3).

    Fix: Create it with groupadd first.

  3. sudo usermod -aG nosuchgroup aman
    usermod: group 'nosuchgroup' does not exist exit status: 6

    What it means: -G names a missing group (exit 6).

    Fix: Check with getent group NAME.

  4. sudo groupdel riya
    groupdel: cannot remove the primary group of user 'riya' exit status: 8

    What it means: It is a user’s primary group (exit 8).

    Fix: Change the user’s primary group, or delete the user.

6 Real-world use

Groups at work

1. Team folders

One group per team owns its shared folders; people join and leave the group.

New team→groupadd→folder

2. Privileged groups

Admin rights come from membership in sudo, wheel or docker; audits review those lists.

Audit→getent group→trim

3. Read-only access

Support staff join adm to read /var/log without becoming admins.

Support→-aG adm→read logs

4. Shared storage

Fixed GIDs keep group ownership correct across servers and NFS.

Plan→groupadd -g→consistent

5. Delegation

Team leads manage their own group without root rights.

Lead→gpasswd -a→no ticket

echo "remove: $(comm -23 <(echo "$current") <(sort roster.txt) | tr '\n' ' ')"
echo "add:    $(comm -13 <(echo "$current") <(sort roster.txt) | tr '\n' ' ')"
sudo gpasswd -M "$(paste -sd, roster.txt)" developers
getent group developers
sudo groupdel developers
remove: add: riya developers:x:2903:aman,riya

comm compares the two sorted lists (Lesson 6.3); paste -sd, joins the roster with commas.

Puzzle answer Remember the question from the story? Open to check your guess.

Yes, it worked: id riya reads /etc/group, which already lists her. Plain id shows the groups of the running shell, loaded at login. Log in again or run newgrp developers. And editing /etc/group with nano is risky (no lock, no check, gshadow not updated): use gpasswd -d, or vigr if you must edit.

Quick check What does gpasswd -M aman developers do to the other members?
Answer: Removes them: -M sets the complete member list.

Quick revision

Lesson 8.3 in one screen

  • Groups give many users the same access. One primary group (passwd field 4), many supplementary (/etc/group field 4).
  • groupadd [-g GID] [-r] [-f], groupmod -n NEW / -g GID, groupdel (not a primary group).
  • usermod -aG a,b USER adds; -G alone replaces; -g changes primary.
  • gpasswd -a USER G, -d USER G, -M a,b G (sets list), -A LEAD G.
  • Membership applies at the next login: newgrp G, su - $USER; id (session) vs id USER (files).
  • Edit by hand only with vigr/vigr -s. Powerful groups: sudo, wheel, docker, adm.

Interview and viva questions

How do I add a user to a group in Linux?

sudo usermod -aG GROUP USER (or sudo gpasswd -a USER GROUP), then the user logs in again.

How do I remove a user from a group?

sudo gpasswd -d USER GROUP.

What is the difference between usermod -G and usermod -aG?

-G replaces all supplementary groups; -aG appends to them.

How do I list members of a group?

getent group GROUP (field 4), or groupmems -g GROUP -l.

How do I create a group with a specific GID?

sudo groupadd -g 2000 NAME.

Why doesn’t my new group work?

Groups are loaded at login: log out and in, or run newgrp GROUP.

How do I rename a group?

sudo groupmod -n NEW OLD (files keep working because the GID is the same).

The interviewer is checking: can you recover?

Show a strong answer

  2. Compare with /etc/group- for other lost groups.
  3. Teach -aG; prefer gpasswd -a in runbooks.

Team folder permissions keep breaking

Files created by one developer cannot be edited by others.

The interviewer is checking: do you know primary groups and SGID?

Show a strong answer

  • umask 002 for group write (Lesson 9.3), or default ACLs (9.5).

Interview and certification corner

Primary vs supplementary group?
Primary: one, owns new files; supplementary: extra access.
How do you create a system group?
groupadd -r NAME.
What does gpasswd -M do?
Sets the complete member list.
Where are group admins stored?
/etc/gshadow.
How do you see members of a group?

What happens to files if you delete a group?
They keep the bare GID.
Why is the docker group dangerous?
Members can run containers that mount / as root.
