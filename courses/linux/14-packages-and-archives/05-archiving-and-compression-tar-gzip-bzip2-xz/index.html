2 Definition

Archiving and compression

Formal definition (write this in exams)

Archiving combines many files and directories into a single file while keeping their names, structure and metadata; on Linux the standard tool is tar. Compression encodes data so it takes fewer bytes; gzip, bzip2 and xz each compress one file or stream. A compressed archive (.tar.gz, .tgz, .tar.xz) uses both; zip archives and compresses in one format.

In simple words

tar joins, gzip/bzip2/xz shrink, zip does both.

Archiving and compression at four depths

Pick your depth. Completely new? Start at Very basic and climb one step at a time.

Very basic No jargon: a suitcase and vacuum bag

tar packs the suitcase; gzip squeezes the air out.

Basic What you will type

  • tar -czf proj.tar.gz proj: create (c), gzip (z), file name (f).
  • tar -tzf proj.tar.gz: list (t). tar -xzf proj.tar.gz: extract (x).
  • gzip big.log → big.log.gz; gunzip big.log.gz back.
  • zip -r proj.zip proj, unzip proj.zip.

Intermediate The differences that matter

  • z gzip (fast, everywhere), j bzip2 (smaller, slow), J xz (usually smallest, slowest to compress, fast to decompress); modern tar also guesses from the name with -a, and extraction auto-detects.
  • Levels -1 (fast) to -9 (small): gzip -9, xz -6 default; XZ_OPT=-9 tar -cJf ….
  • gzip, bzip2 and xz replace the original file; -k keeps it, -c writes to stdout.
  • tar strips the leading / so extracting never overwrites system paths by surprise; use -C DIR to choose where to extract.

Advanced Behind the screen: blocks, dictionaries and entropy

  • A tar file is a sequence of 512-byte headers (name, mode, owner, size, mtime) each followed by the file’s data, ending with two zero blocks: no index, so listing reads the whole archive.
  • gzip uses DEFLATE (LZ77 + Huffman) with a 32 KB window; bzip2 the Burrows–Wheeler transform; xz LZMA2 with windows up to 64 MB+, which is why it finds more repetition.
  • Random or already-compressed data (JPEG, MP4, .gz, encrypted files) has high entropy: nothing to squeeze, and headers make it slightly larger.
  • zip compresses each file separately and keeps a central directory at the end: fast single-file extraction, worse ratio than .tar.xz.

Did you know? The letters in tar -czvf do not need a dash at all (tar czvf, the old style), but f must come last because the next word is its file name: tar -cfz x.tar creates an archive called z.

Exam tip: “What is the difference between tar and gzip?” → tar archives (joins many files into one, keeping metadata) without compressing; gzip compresses a single file. tar -z runs gzip on the archive.

Quick check Which option letters create a bzip2-compressed tar archive?
Answer: tar -cjf name.tar.bz2 DIR (j = bzip2).
Common mistake
✗tar -czf ~/proj proj.tar.gz (arguments swapped)
✓tar -czf proj.tar.gz ~/proj (archive name right after f)

With the order swapped, tar tries to write an archive named after your folder and fails, or worse, overwrites a file.

Common mistake
✗extracting an unknown archive straight into your home
✓tar -tzf A.tar.gz | head first; then tar -xzf A.tar.gz -C ~/x

Some archives have no top folder and spill hundreds of files, or overwrite files with the same names.

Undo and safety net

Archives are safe; the dangers are overwriting and replacing.

  • gzip replaced the original: gunzip FILE.gz gives it back exactly (lossless); use -k next time.
  • Extracted into the wrong place: list the members (tar -tzf A | xargs …) to delete exactly what was extracted.
  • Overwrote newer files on extract: restore from another copy; next time --keep-newer-files or -k (keep existing).
  • Wrong archive name order: check with ls -l; delete the bad archive and rerun.

Error messages decoded

Errors students see most (really run on our build machine).

  1. cd ~ && tar -xzf proj.tar
    tar (child): proj.tar: Cannot open: No such file or directory tar (child): Error is not recoverable: exiting now tar: Child returned status 2 tar: Error is not recoverable: exiting now exit status: 2

    What it means: No such archive here.

    Fix: Check the name and path with ls.

  2. cd ~/proj && tar -xzf README.md
    gzip: stdin: not in gzip format tar: Child returned status 1 tar: Error is not recoverable: exiting now exit status: 2

    What it means: Not a gzip file: the file is plain text (or you used z on a non-gz archive).

    Fix: Check with file NAME; drop z or use the right letter.

  3. cd ~ && tar -czf
    tar: option requires an argument -- 'f' Try 'tar --help' or 'tar --usage' for more information. exit status: 64

    What it means: Option f needs a file name.

    Fix: tar -czf NAME.tar.gz DIR.

  4. cd ~ && tar -cf bk/a.tar proj && gzip bk/a.tar && tar -rf bk/a.tar.gz README.md
    tar: Cannot update compressed archives tar: Error is not recoverable: exiting now exit status: 2

    What it means: You cannot append to a compressed archive.

    Fix: Append to the .tar first, then compress.

6 Real-world use

Archives and compression at work

1. Nightly backups

cron runs tar -czf /backup/app-$(date +%F).tar.gz with excludes, then checks it and deletes old ones.

cron→tar + date→rotate

2. Log rotation

logrotate gzips old logs: 1 GB of text becomes about 100–300 MB; zgrep still searches them.

Old logs→gzip→zgrep

3. Software releases

The Linux kernel and GNU projects publish .tar.xz tarballs with checksums and signatures.

Build→tar -cJf→publish

4. Data engineering

Hadoop and Spark prefer splittable formats (bzip2, or Parquet with Snappy/zstd); a single .gz cannot be split between workers.

Raw CSV→compress→Spark

5. Container images

Each Docker image layer is a tar archive, usually gzip- or zstd-compressed.

Dockerfile→layer = tar→registry

Examples are simplified and generic. They describe common patterns, not the internal systems of any particular company.

Why repetition compresses

gzip and xz are far smarter, but the idea is the same: repeats are written shorter. Random text gets longer.

# Run-length encoding: the simplest compression idea (repeats become counts)
rle(){ echo -n "$1" | fold -w1 | uniq -c | awk '{printf "%s%s", $1, $2} END{print ""}'; }
for s in aaaaaaaabbbbcc ERRORERRORERROR abcdefgh; do
  out=$(rle "$s"); echo "$s (${#s}) -> $out (${#out})"
done
aaaaaaaabbbbcc (14) -> 8a4b2c (6) ERRORERRORERROR (15) -> 1E2R1O1R1E2R1O1R1E2R1O1R (24) abcdefgh (8) -> 1a1b1c1d1e1f1g1h (16)
  • uniq -cCounts runs of the same character.
  • abcdefghNo repeats: the “compressed” form is longer.

Quick revision

Lesson 14.5 in one screen

  • tar archives (c create, t list, x extract, f file, v verbose, -C dir); it does not compress by itself.
  • z gzip (fast), j bzip2, J xz (usually smallest; measure); extraction auto-detects; -a picks by extension.
  • gzip, bzip2, xz replace the file (-k keeps it); zcat, zless, zgrep read without unpacking.
  • zip -r and unzip for Windows; zip compresses per file and loses Unix owners.
  • --exclude, single members, --wildcards, --strip-components, tar -d to compare.
  • Backups: dated name, test (gzip -t, tar -t), checksum, restore test, rotation.

Interview and viva questions

How do I extract a tar.gz file in Linux?

tar -xzf file.tar.gz (add -C DIR to choose where).

What is the difference between tar and zip?

tar only archives (compression is added with gzip/xz) and keeps Unix permissions; zip archives and compresses per file and is native on Windows.

Which is better, gzip or xz?

xz usually makes smaller files, gzip is much faster; use gzip for everyday and logs, xz for releases.

How do I see what is inside an archive?

tar -tzf A.tar.gz, unzip -l A.zip.

How do I extract one file from a tar?

Name it after the archive: tar -xzf A.tar.gz path/in/archive.

Why does tar remove the leading slash?

So extraction never writes to absolute system paths by accident.

What is a .tgz?

Same as .tar.gz.
