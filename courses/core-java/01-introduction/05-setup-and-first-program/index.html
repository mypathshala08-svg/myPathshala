Installing Java and your first program

Time to set up your own machine. You'll install a JDK, make your computer find it, write your first program in a real editor and run it from the terminal. You'll also meet the five errors almost every beginner hits on day one, so they won't scare you when they appear.

2 Definition

What does “setting up Java” mean?

Formal definition (write this in exams)

Setting up a Java development environment means installing a JDK, making its tools reachable through the PATH environment variable (and usually setting JAVA_HOME to the JDK's install directory), and choosing a source editor or IDE. A first Java program is a public class saved in a file of the same name with a public static void main(String[] args) method, compiled with javac and executed with java.

In simple words

Install the JDK, tell your computer where its tools are, pick an editor, and you're ready. Your first program is a class with a main method. Save it with the same name as the class, compile it with javac, and run it with java plus the class name.

Words you'll meet in this lesson

PATHA list of folders your operating system searches when you type a command like java.
JAVA_HOMEA variable holding the JDK's top folder. Build tools and IDEs read it.
IDEIntegrated Development Environment: an editor with compile, run and debug built in (IntelliJ IDEA, Eclipse, VS Code).
TerminalA text window for typing commands: Command Prompt or PowerShell on Windows, Terminal on macOS and Linux.
Command-line argumentsExtra words after java Hello, which arrive in args.
Escape sequenceSpecial characters inside a string, like \n (new line) and \t (tab).

4 Step by step

Install, check, write, compile, run

  1. Install the JDK

    Download Eclipse Temurin 21 (LTS) for your operating system from adoptium.net and run the installer. On Windows, tick the options “Set JAVA_HOME variable” and “Add to PATH” if the installer offers them.

    The installer copies the JDK folder (bin, lib, conf…) to a location like C:\Program Files\Eclipse Adoptium\jdk-21… on Windows or /Library/Java/JavaVirtualMachines/ on macOS.

  2. Set JAVA_HOME and PATH (if not done)

    Windows: search “Environment Variables” → New system variable JAVA_HOME = the JDK folder → edit Path → add %JAVA_HOME%\bin and move it to the top. macOS/Linux: add these lines to ~/.zshrc or ~/.bashrc:

    export JAVA_HOME=$(/usr/libexec/java_home -v 21)   # macOS
export PATH="$JAVA_HOME/bin:$PATH"
    PATH is searched from first folder to last. Putting the JDK's bin first makes sure your terminal uses this JDK even if an older Java exists elsewhere.

  3. Open a NEW terminal and check

    java -version
javac -version
    Terminals read environment variables only when they start, so an old window won't see your changes. Both commands should show the same version.

  4. Write your first program

    Make a folder such as C:\java-practice, open it in your editor, and create Hello.java:

    public class Hello {
    public static void main(String[] args) {
        System.out.println("Namaste, MyPhatshala!");
    }
}
    Namaste, MyPhatshala!
    The editor saves plain text. Use “Save as” and check the name really is Hello.java, not Hello.java.txt (Windows can hide extensions).

  5. Compile and run

    cd C:\java-practice
javac Hello.java
java Hello
    Namaste, MyPhatshala!
    cd moves into your folder, because javac and java look for files in the current folder. javac writes Hello.class; java Hello asks the JVM to load the class named Hello and run its main.
5 See it happen

From installer to first output: both views

Six moments in Kabir's setup. Left: his screen. Right: what the operating system and Java are doing.

Kabir's first program 6 steps
What you see
  1. Kabir runs the Temurin JDK 21 installer and ticks “Add to PATH” and “Set JAVA_HOME”.
  2. In Environment Variables, JAVA_HOME points to the JDK, and %JAVA_HOME%\bin is at the top of Path.
  3. In a new terminal, java -version and javac -version both show 21.
  4. He writes Hello.java. The public class is named Hello, exactly like the file.
  5. javac Hello.java, then java Hello: Namaste, MyPhatshala!
  6. Typing java Hello.class fails. The java command wants the class name, not the file name.
Behind the screen
  1. The installer copies the JDK: bin holds the tools, lib holds the class libraries.
  2. PATH is for the operating system to find commands. JAVA_HOME is for other tools to find the JDK.
  3. Typing java makes Windows search PATH folders top to bottom. The first java.exe found wins.
  4. javac enforces the rule: public class name = file name, including capital letters.
  5. java Hello asks the class loader to find Hello.class in the current folder, verify it and call main.
  6. In java Hello.class, the dot is read as a package separator, so the JVM looks for Hello/class.class and fails.
6 Real-world use

How developers set up Java at work

At home you install one JDK. At work, setups are a little more organised. Here's what you'll meet in your first job.

Animated example
  1. Start: the folder has only the source file Hello.java.
  2. Compile: javac Hello.java checks the code and writes Hello.class. If javac prints nothing, it worked.
  3. Run: java Hello starts a JVM. Note: the class name, without .class.
  4. Entry point: the JVM looks inside the class for exactly public static void main(String[] args).

1. Several JDKs on one laptop

Developers often maintain an older project on Java 17 and a new one on Java 21. Tools such as SDKMAN! (macOS/Linux) or the IDE's own JDK settings let you switch per project without breaking anything.

Project A → JDK 17·SDKMAN / IDE settings·Project B → JDK 21

2. IDE projects instead of single files

In a company, you rarely compile files by hand. IntelliJ IDEA or Eclipse opens a Maven or Gradle project, downloads libraries and compiles everything when you press Run. Knowing javac and java still helps you understand what the Run button does.

Open project→IDE runs javac + java for you→Output pane

3. The Java version written into the project

Teams record the Java version in the build file (for example <maven.compiler.release>21</maven.compiler.release>) and sometimes a version file in the repository, so every developer and the build server use the same version.

pom.xml / build.gradle→release 21→Same everywhere

4. Ready-made dev containers and cloud IDEs

Some teams give new joiners a dev container or cloud workspace with the right JDK, tools and settings already installed. You open it and start coding on day one.

Open repo→Container with JDK 21→Code immediately

5. Interview coding rounds

Online assessments and coding interviews often use a browser editor where only the class name Main or Solution works, exactly like the live editor below. Knowing the class-name rule saves panic in the middle of a test.

Online test→public class Main / Solution→Submit

Examples are simplified. Every company has its own setup guide; read it on your first day.

7 Run the code

Your first real programs

Here's a slightly bigger first program with notes. The live editor uses the class name Main, so the challenges do too.

public class Hello {
    public static void main(String[] args) {
        System.out.println("Namaste, MyPhatshala!");
        System.out.println("Arguments received: " + args.length);
        System.out.println("Java\tis\tfun");
    }
}
Namaste, MyPhatshala! Arguments received: 0 Java is fun
  • public class HelloThe class name. Save the file as Hello.java, with a capital H.
  • String[] argsHolds any words typed after the class name. java Hello Riya Kharghar would make args.length 2.
  • args.lengthHow many arguments arrived. With plain java Hello it's 0.
  • "Java\tis\tfun"\t is an escape sequence for a tab. Others: \n new line, \" a double quote, \\ a backslash.

9 Quiz and revision

Check yourself

Quick revision

Lesson 1.5 in one screen

  • Install an LTS JDK (21 or 25), e.g. Eclipse Temurin. Check with java -version and javac -version.
  • PATH: the OS finds commands (first match wins). JAVA_HOME: tools find the JDK folder.
  • Open a new terminal after changing variables.
  • Public class name = file name, case-sensitive. One public class per file.
  • javac Hello.java (file name) → java Hello (class name). Or java Hello.java for quick runs.
  • Entry point: public static void main(String[] args); args holds command-line words.
  • Escape sequences: \n \t \" \\.

Interview and viva questions

Can a Java file have more than one class?

Yes, but at most one public class, and the file must be named after it. javac creates a separate .class file for every class in the file.

Can the file name differ from the class name?

Only if the class is not public. For example, a non-public class Test can be saved in Practice.java, and javac will produce Test.class. For public classes, the names must match.

What's the difference between PATH and JAVA_HOME?

PATH is an operating-system list of folders searched for commands, so it lets you type java anywhere. JAVA_HOME is a convention used by other tools (Maven, Gradle, Tomcat, Kafka, IDEs) to find which JDK to use. You usually set both, with PATH including JAVA_HOME/bin.

What is the difference between print and println?

print writes the text and stays on the same line. println writes the text and then a line break. printf writes formatted text, for example System.out.printf("Total: %d%n", 60).

What happens if you write main without static?

On classic Java versions the program compiles, but java Main reports that the main method was not found, because the JVM calls main without creating an object first, which requires it to be static. (Java 25 relaxed these rules for simple programs, but the classic form works everywhere.)

Real-world scenario questions (asked in company interviews)

Setup problems are some of the first things you'll solve in a new job. Decide your answer first, then open the model answer.

Online assessment · campus hiringFresher

Your code won't compile in the online test

In a timed online coding test, your solution works on your laptop, where the class is called BankAccountSolver. When you paste it into the test's editor and press Run, you get a compile error about the class being public and the file name. The timer is running.

The interviewer is checking: can you read an error quickly and calmly, and do you know the file-name rule?

Show a strong answer

The online editor saves the code in a fixed file, usually Main.java or Solution.java. A public class must match that file name, so public class BankAccountSolver fails.

  • Rename the public class to the name the platform expects (read the starter code or instructions; usually Main or Solution).
  • Helper classes can stay, but without the public keyword.
  • Also check that the platform's expected main method or function signature hasn't been changed.

Avoid: rewriting your logic in a panic. The logic is fine; only the class name is wrong.

IT services · first weekFresher

Two projects, two Java versions

You're assigned to two projects: a maintenance project on Java 17 and a new microservice on Java 21. If you change PATH for one, the other's build breaks. Your lead asks how you'll set up your laptop.

The interviewer is checking: do you know how professionals manage several JDKs without fighting with PATH every day?

Show a strong answer
  • Install both JDKs side by side; they don't conflict on disk.
  • In the IDE, set the Project SDK separately for each project (IntelliJ: Project Structure → SDK).
  • For the command line, use a version manager such as SDKMAN! on macOS/Linux, or a small script per project that sets JAVA_HOME and PATH before building.
  • Rely on each project's build file (maven.compiler.release or Gradle toolchains) to declare its Java version, so builds are predictable.

Avoid: uninstalling and reinstalling JDKs every time you switch projects.

Any company · support ticketFresher

“Could not find or load main class” on a colleague's machine

A tester runs java com.shop.App inside the project's target/classes folder and it works. A colleague runs java App from inside target/classes/com/shop and gets Could not find or load main class App. They ask you why the same class works for one and not the other.

The interviewer is checking: do you understand that the class loader finds classes using the full class name and the classpath, not just the file?

Show a strong answer

The class is in the package com.shop, so its real name is com.shop.App. The class loader turns that into the path com/shop/App.class and searches for it starting from each classpath folder.

  • The tester ran from target/classes, so com/shop/App.class was found.
  • The colleague asked for a class called just App from inside the package folder, so the name and the location don't match.
  • Fix: run from the classpath root with the full name, or use java -cp target/classes com.shop.App from anywhere. Packages are covered in Lesson 6.6.

Avoid saying: “The class file must be corrupted.”

Any company · laptop setupFresher

IntelliJ runs it, the terminal doesn't

Your program runs perfectly with IntelliJ's Run button. In the terminal, javac isn't recognised at all. A senior asks: “If IntelliJ can compile it, Java must be installed. What's going on?”

The interviewer is checking: do you understand that an IDE can use its own JDK, separate from the system PATH?

Show a strong answer

IntelliJ can download and use a JDK of its own and remembers its location in the project settings. The terminal doesn't know about that: it only searches the folders in PATH.

  1. Find the JDK IntelliJ uses (Project Structure → SDK shows its path).
  2. Set JAVA_HOME to that folder and add its bin to PATH (or install a JDK system-wide).
  3. Open a new terminal and confirm with javac -version.

Avoid: concluding that Java is “half installed”. Two programs are simply looking in different places.
