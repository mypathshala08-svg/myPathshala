2 Definition

What are String methods?

Formal definition (write this in exams)

String methods are instance methods of java.lang.String that inspect, search, extract or transform the characters of a String. Because String is immutable, every method that produces modified text returns a new String and leaves the original unchanged. Index-based methods use positions from 0 to length() - 1; search methods return -1 when nothing is found.

In simple words

Ready-made tools for text: find something, cut a piece, clean it up, join pieces together. They never damage the original; they hand you a new result.

Method chainings.trim().toLowerCase(): each call works on the previous result.

replace vs replaceAll, trim vs strip, isEmpty vs isBlank

replace / replaceAll

replace works on plain text (all occurrences). replaceAll takes a regex: replaceAll("[0-9]", "#") hides every digit.

Plain text vs pattern

trim / strip

Both remove spaces at the ends. strip() (Java 11) also understands Unicode spaces; prefer it in new code.

Ends only

isEmpty / isBlank

isEmpty(): length is 0. isBlank() (Java 11): empty or only spaces. Use isBlank for form fields.

"" vs " "

The split trap: split takes a regular expression. "a.b.c".split(".") returns an empty array, because . means “any character”. Write split("\\."). The same applies to |, *, + and ?. Also, trailing empty pieces are dropped: "a,b,,".split(",") has only 2 elements.

4 Step by step

Cleaning and cutting an email

  1. Clean

    String email = raw.trim().toLowerCase();
    trim() returns a new String without outer spaces; toLowerCase() is called on that result and returns another new String. Two objects created, the original untouched.

  2. Find

    int at = email.indexOf('@');
    indexOf scans from index 0 until it finds the character, returning its position, or -1 if it reaches the end.

  3. Cut

    String user = email.substring(0, at);
String domain = email.substring(at + 1);
    substring(0, at) stops before the @. substring(at + 1) starts just after it and runs to the end. Each creates a new String with copied characters.

  4. Check

    boolean gmail = domain.equals("gmail.com");
    Compare content with equals (Lesson 4.4). Since we lower-cased earlier, "Gmail.COM" also matches.

  5. Build the message

    String msg = String.format("Hi %s, see you at the fest!", user);
    String.format puts values into a pattern: %s for text, %d for whole numbers, %.2f for 2 decimals.

Indexes, indexOf and substring: both views

Cutting "riya@mail.com" 6 steps
What you see
  1. trim(): removes the spaces at both ends. 13 characters remain.
  2. toLowerCase(): R and M become small letters. Stored back in s.
  3. indexOf('@'): returns 4. For a character that isn't there, it returns -1.
  4. substring(0, 4): takes indexes 0, 1, 2, 3 → "riya". Length = 4 − 0 = 4.
  5. substring(5): one argument means “to the end”: "mail.com".
  6. split("@"): cuts at every @ and returns a String[] of the pieces (Lesson 4.1).
Behind the screen
  1. trim() found the first and last non-space characters and copied the part between them into a new String.
  2. toLowerCase() creates another String; only indexes 0 and 5 actually changed letters.
  3. indexOf checks index 0, 1, 2, 3, then finds '@' at 4 and stops. It returns the first match only; lastIndexOf searches from the end.
  4. The end index is a “stop before” marker. That's why substring(0, at) neatly excludes the @.
  5. substring(begin) is short for substring(begin, length()).
  6. split finds each match of the pattern and collects the text between matches into a new array.

9 Quiz and revision

Check yourself

Quick revision

Lesson 4.5 in one screen

  • Families: inspect, search, extract, transform, compare, build.
  • All return new Strings: s = s.trim();
  • indexOf / lastIndexOf → position or -1; indexOf(x, from) continues a search.
  • substring(begin, end): end excluded, length = end − begin; substring(begin) to the end.
  • split and replaceAll take regex: escape . as "\\."; "\\s+" for any spaces.
  • isBlank() for form fields; strip() in new code.
  • String.join, repeat, String.format (%s %d %.2f %-10s %05d) build text.

Interview and viva questions

What's the difference between replace() and replaceAll()?

Both replace every occurrence. replace treats its arguments as plain text (char or CharSequence). replaceAll treats the first argument as a regular expression, so special characters like . or $ have meaning and need escaping.

Why is substring's end index exclusive?

It makes the maths simple: the length is end - begin, and adjacent ranges join without overlap, e.g. s.substring(0, i) + s.substring(i) is always the original string.

What's the difference between trim() and strip()?

trim() removes characters with codes up to 32 (space and control characters). strip(), added in Java 11, removes all Unicode whitespace, including special spaces that come from copy-pasted web text.

How do you split a string on a dot or a pipe?

Escape it, because split takes a regex: split("\\."), split("\\|"), or use split(Pattern.quote(".")).

How do you convert between Strings and numbers?

Text to number: Integer.parseInt("42"), Double.parseDouble("3.5") (throws NumberFormatException for bad text). Number to text: String.valueOf(42), Integer.toString(42) or "" + 42.

P6Medium

Count a word inside text

Count how many times “java” appears in a paragraph, ignoring case, including overlapping positions.

public class Main {
    public static void main(String[] args) {
        String text = "Java is great. I use JAVA daily; javascript is different.";
        String hay = text.toLowerCase(), needle = "java";

P11Business problem

Mask an email for display

Show an email as r*********a@mail.com: keep the first and last letter of the user part, hide the rest.

Input
"riya.sharma@mail.com", "ab@mail.com"
Expected output
r*********a@mail.com
a*@mail.com
Show solution and explanation 
public class Main {
    public static void main(String[] args) {
        String[] emails = {"riya.sharma@mail.com", "ab@mail.com"};
        for (String email : emails) {
            int at = email.indexOf('@');
            String user = email.substring(0, at);
            String masked;
            if (user.length() <= 2) {
                masked = user.charAt(0) + "*";
            } else {
                masked = user.charAt(0) + "*".repeat(user.length() - 2) + user.charAt(user.length() - 1);
            }
            System.out.println(masked + email.substring(at));
        }
    }
}
r*********a@mail.com a*@mail.com

How it works: "*".repeat(n) (Java 11+) makes n stars. Very short user names are handled separately so nothing breaks. “Forgot password” pages show masked emails so a stranger can't learn someone's full address.

Blog URLs use a “slug”: lower case, words joined by hyphens, no symbols. Turn titles into slugs.

public class Main {

        String[] titles = {"Top 10 Java Tips for 2026!", "  String vs StringBuilder: Which?  "};

            String slug = title.trim().toLowerCase()

P13Business problem

Print an aligned receipt

Print a shop receipt with item names left-aligned and amounts right-aligned with 2 decimals.

Input
items: Notebook 2 x 45.00, Gel pen 5 x 12.50, Geometry box 1 x 120.00
Expected output
Item           Qty    Amount
----------------------------
Notebook         2     90.00
Gel pen          5     62.50
Geometry box     1    120.00
----------------------------
TOTAL                 272.50
Show solution and explanation 
public class Main {
    public static void main(String[] args) {
        String[] items = {"Notebook", "Gel pen", "Geometry box"};
        int[] qty = {2, 5, 1};
        double[] price = {45.00, 12.50, 120.00};
        double total = 0;
        System.out.println(String.format("%-14s %3s %9s", "Item", "Qty", "Amount"));
        System.out.println("-".repeat(28));
        for (int i = 0; i < items.length; i++) {
            double amount = qty[i] * price[i];
            total += amount;
            System.out.println(String.format("%-14s %3d %9.2f", items[i], qty[i], amount));
        }
        System.out.println("-".repeat(28));
        System.out.println(String.format("%-18s %9.2f", "TOTAL", total));
    }
}
Item Qty Amount ---------------------------- Notebook 2 90.00 Gel pen 5 62.50 Geometry box 1 120.00 ---------------------------- TOTAL 272.50

How it works: in String.format, %-14s pads text to 14 characters on the right (left-aligned), %3d right-aligns a number in 3 spaces, and %9.2f shows 2 decimals in 9 spaces. Fixed widths line the columns up.

The version check that always says “update required”

An app compares versions like "2.10.3" by doing String[] p = version.split("."); and reading p[0]. It crashes with ArrayIndexOutOfBoundsException. Why?

The interviewer is checking: do you know split takes a regular expression?

Show a strong answer
  • In regex, . means “any character”. Every character is a separator, all pieces are empty, and trailing empty pieces are removed, so the array has length 0.
  • Fix: split("\\.") or split(Pattern.quote(".")).
  • Then compare the parts as numbers with Integer.parseInt; comparing "10" and "9" as text says "10" is smaller.

Avoid: comparing whole version strings with compareTo: "2.10.3" sorts before "2.9.0" as text.

Logistics · addressesFresher

PIN code extraction crashes on short addresses

Code takes the last 6 characters of an address as the PIN: addr.substring(addr.length() - 6). It works for most rows but crashes for an address entered as "Pune", and returns garbage like "Road 5" for others. How do you make it robust?

The interviewer is checking: do you validate before cutting, and think about messy input?

Show a strong answer
  • For "Pune", length() - 6 is negative → StringIndexOutOfBoundsException. Always check the length (or the indexOf result) before substring.
  • Position-based cutting assumes a fixed format. Instead, search for a 6-digit number, e.g. with a regex like \\b\\d{6}\\b, or scan tokens from split("\\s+") for one that's 6 digits.
  • Best: collect the PIN in its own form field and validate it there.

Avoid: catching the exception and returning an empty PIN silently. Flag bad records for review.

Finance · data import1–3 years

The CSV import that shifts columns

A bank-statement import uses line.split(","). Two problems appear: rows like 101,"Sharma, Riya",500 get 4 columns instead of 3, and rows ending with empty fields (102,Kabir,,) have fewer columns than expected. Explain both and what you'd do.

The interviewer is checking: do you know split's limits and when to use a proper parser?

Show a strong answer
  • Split doesn't understand CSV quoting, so the comma inside "Sharma, Riya" is treated as a separator.
  • split(",") drops trailing empty strings; split(",", -1) keeps them so the column count stays correct.
  • For real files use a CSV library (for example Apache Commons CSV or OpenCSV), which handles quotes, escaped quotes and line breaks inside fields.
  • Validate the column count of every row and report bad rows instead of guessing.

Avoid: writing your own quote-handling with more and more indexOf calls. It never covers every case.

Global SaaS · localisation1–3 years

Login works everywhere except Turkey

A permission check does if (role.toLowerCase().equals("admin")). Customers in Turkey report that admins named with the role "ADMIN" lose access. Nothing is wrong with their data. What could be happening?

The interviewer is checking: do you know that case conversion depends on the default locale?

Show a strong answer
  • toLowerCase() without arguments uses the JVM's default locale. In Turkish, upper-case I lowers to a dotless ı, so "ADMIN" becomes "admın", which doesn't equal "admin".
  • For identifiers, codes and keys, use toLowerCase(Locale.ROOT), or simply equalsIgnoreCase.
  • Keep locale-sensitive conversion only for text shown to users.
  • Add a test that runs with a Turkish default locale.

Avoid: “It works on my machine.” Server and user locales differ.
